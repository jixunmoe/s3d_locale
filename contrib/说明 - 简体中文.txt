Simplify3D 5.1.2 (Win64) 外挂本地化开发包 v0.4

================================================================================

提供的简繁体中文翻译文件为测试外挂翻译效果制作，基于日语翻译文件清空制作。

源程序没有提供英文版本的翻译文件，因此如果有条目缺失请尝试翻阅其他语言的档案。

================================================================================

外挂模组使用说明：

1. 将 version.dll 与 locale 目录复制到主程序目录
   例: C:\Program Files\Simplify3D-5.1.2
2. 导入对应的语言配置档，或进入程序后选择最下方的「西班牙语」或「葡萄牙语」。
   ※ 参考下方「外挂语言包切换」段落。

================================================================================

支持的文件校验：

  File: Simplify3D.exe
SHA256: 03C0EF8EAB59C850828FB276889133736A0C36C488219E770111D996FC41D2C7

================================================================================

外挂语言包切换：

  询问语言时，选择一项：
    - 简体中文: “Spanish - Español”
    - 正體中文: “Portuguese - Português”

或导入提供的注册表文件。

================================================================================

本地化开发说明：

1. 下载 Qt Linguist 6.7.2
   https://github.com/thurask/Qt-Linguist/releases/tag/20240722
2. 使用 Qt Linguist 对 zh-CN.ts 或 zh-TW.ts 进行翻译。
3. 使用 File -> Release 生成 zh-CN.qm 或 zh-TW.qm 本地化文件。
4. 将文件放到主程序所在目录下的「locale」目录并覆盖同名文件。
